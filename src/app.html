Generatore Attestati

Crea un attestato Word per ogni persona dell'elenco Excel, in un colpo solo.

1 Modello Word dell'attestato

Il file .docx con i segnaposto tra parentesi graffe, ad esempio {NOME}, {COGNOME}, {CODICE_FISCALE}.

Trascina qui il file Word oppure clicca per sceglierlo

2 Elenco Excel delle persone

Una persona per riga. La prima riga contiene le intestazioni, uguali ai segnaposto del modello (senza parentesi).

Trascina qui il file Excel oppure clicca per sceglierlo

3 Dove salvare gli attestati

Scegli la cartella in cui verranno creati i file (consigliato: la stessa cartella del file Excel).

4 Nome dei file

Scrivi il nome come vuoi, usando testo libero e i campi tra graffe, ad esempio Azienda-attestato-{NOME} {COGNOME}. Clicca su un campo per inserirlo.
